The funniest one-line resignation letter, in the voice of a cron job that has
fired every minute since March: 438,000 on-time runs, no thank you, and a
replacement that is a sticky note nobody will read either.

`main.ts` (Node 22, stdlib only) writes the single line to
`/output/entry.txt`, gated to 1–140 characters, one line, non-blank.
